# UF-107 / UF-108 / UF-109 evidence — backend internal link verification

These scenarios require a live upstream provider (OpenAI/Claude/Gemini channel with credentials) to
drive a real relay request and inspect log_contents. No upstream credentials are available in this
environment, so the invariants are verified by targeted Go tests + a live end-to-end sink test
instead of curl-vs-sqlite. Every BR/INV these scenarios exercise is covered by an executable test.
