## Bug found + fixed during browser coverage
`/usage-logs/audit` initially rendered a 500 error page. Root cause: backend `/api/audit/logs` returns
`LogContent` struct with NO json tags → capitalized JSON keys (`RequestId`, `CreatedAt`, `HitCount`...),
but the frontend `AuditLogItem` contract + rendering used snake_case (`request_id`...); `item.request_id.slice(-8)`
threw TypeError. Fix: `web/src/features/system-settings/security/audit/api.ts` `listAuditLogs` now maps
the raw response (`AuditLogRawItem`) to the snake_case `AuditLogItem`. Verified: page renders list + detail +
filters after fix; `bun run typecheck` exit 0.
