## Non-admin isolation (403)

- GET /api/audit/templates as smoke_user → HTTP 403
- GET /api/audit/logs as smoke_user → HTTP 403

Middleware evidence: `middleware/auth.go` `AdminAuth()` → `authHelper(c, common.RoleAdminUser)` → `if user.Role < minRole { c.AbortWithStatusJSON(http.StatusForbidden, ...) }` (AUTH_INSUFFICIENT_PRIVILEGE).

All 8 new routes are registered inside `auditRoute` (router/api-router.go L283-300) wrapped in `middleware.AdminAuth()`.
Frontend: `web/src/routes/_authenticated/usage-logs/$section.tsx` beforeLoad throws redirect to /403 for `section === 'audit'` when not admin.
